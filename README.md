# Movie Recommendation and Booking Engine Using Machine Learning

## Overview

Movie Recommendation and Booking Engine is an intelligent web application that provides personalized movie recommendations using Machine Learning and Natural Language Processing techniques. The system analyzes movie metadata and user preferences to suggest relevant movies while also providing booking functionality through an interactive web interface.

## Features

### User Features

* User Registration and Authentication
* Secure Login System
* Personalized Movie Recommendations
* Movie Search and Filtering
* Movie Details and Poster Display
* Movie Ticket Booking
* Booking History Management

### Recommendation Engine

* Content-Based Recommendation System
* TF-IDF Vectorization
* Cosine Similarity Matching
* K-Nearest Neighbors (KNN) Algorithm
* NLP-Based Movie Description Analysis

### Data Integration

* TMDB API Integration
* Real-Time Movie Information
* Movie Poster Retrieval
* Metadata Processing and Cleaning

## Machine Learning Workflow

1. Data Collection from TMDB Dataset
2. Data Cleaning and Preprocessing
3. Feature Extraction using TF-IDF
4. Similarity Computation using Cosine Similarity
5. Recommendation Generation using KNN
6. Interactive Recommendation Delivery through Streamlit
